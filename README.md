# 바나프레소 신규 입점 입지 추천 시스템

> 공공데이터와 웹 크롤링을 기반으로 기존 매장의 입지 패턴을 분석하고,
> 신규 매물을 점수화해 최적 입점 후보지를 추천하는 데이터 기반 입지 분석 시스템

**팀원:** 김단하 · 김민정 · 조승아 (3인) | **기간:** 2026.01.19 ~ 03.06 (약 7주)

## 🎯 문제 정의 (Why)

대부분의 예비 창업자는 데이터 분석 없이 직관과 경험에 의존해 입지를 결정한다.
"어디에 열어야 잘 될까?"라는 질문에 근거를 제시하는 도구가 없다는 문제에서 출발했다.
서울 내 바나프레소 기존 매장 데이터를 분석해 '이상적 입지 프로파일'을 도출하고,
신규 매물을 점수화하여 최적 입점 후보지를 추천한다.

---

## 👤 나의 역할 (Who)

- **데이터 수집·전처리**: 공공데이터포털 5종 API 수집·정제, 직방 매물 Scrapy 크롤링
- **Rule-based 점수화 모델** 설계 (`rule_base_modeling.ipynb`)
- **최종 통합 분석** (`BANA_final.ipynb`) — Rule-based·ML·LLM 결과 통합

## ⚙️ 분석 방법 (How) — 왜 이렇게 했나

**Rule-based와 ML을 병행한 이유**
기준 매장이 63개(폐업 4개 포함)로 표본이 작아, ML 단독 예측은 과적합 위험이 있다고 판단했다.
그래서 정확한 예측 모델을 만들기보다, **입지 특성을 정량화하고 추천 구조를 설계하는 데 초점**을 두었다.
Rule-based 점수를 주 지표로, Logistic Regression 점수를 보조 지표로 병행했다.

## 🗺 결과 시각화

- **Folium 지도**: 기존 매장의 성공·실패 분포와 추천 매물 TOP을 하나의 지도에 시각화해
  공간적 출점 패턴을 직관적으로 확인
- **LLM 자연어 해석**: OpenAI API로 TOP 3 추천 매물의 입지 장점·리스크를 자동 생성해
  추천 결과의 설명 가능성(explainability)을 높임

---

## 💡 핵심 인사이트

1. **오피스 상권 중심** — 점심 유동인구가 가장 중요한 변수, 직장인 밀집 지역 출점 패턴
2. **가시성·접근성 핵심** — 대부분 대로변 + 1층, 지하철역 평균 280m 이내
3. **소비력 기반 전략** — 고가 카페 밀집 = 소비력 높은 상권 신호

---

## ⚠️ 한계 및 회고

- **표본 한계**: 학습 데이터가 59개로 매우 제한적이라, 모델이 성공 패턴을 안정적으로
  일반화하기엔 한계가 있었다. 이 때문에 ML 점수는 단독 판단이 아닌 보조 지표로 활용했다.
- **초점 전환**: 제한된 데이터 환경을 고려해, 정확한 예측 모델 구축보다 **입지 특성 정량화와
  추천 구조 설계**에 분석의 초점을 두었다.
- **다음 단계**: 유사 저가 커피 프랜차이즈 데이터를 포함해 학습 데이터를 수백~수천 건 규모로
  확장하면 일반화 성능을 개선할 수 있을 것으로 보인다.
